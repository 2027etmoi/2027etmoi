Tout est sourcé

Chaque statut, mesure, élément de biographie, sondage ou chiffre renvoie à sa source, avec sa date. Rien n'est inventé ; en cas de doute, l'information n'est pas publiée.

Tout est public

Le code du site, toutes les données et l'historique de chaque modification sont consultables sur GitHub. Les règles de sourçage sont publiées : programmes, biographies, données.

Chacun peut vérifier

Une erreur, un oubli, une source plus récente ? Signalez-le sur GitHub en indiquant la page et, si possible, une source. Les corrections sont visibles publiquement.

La liste officielle des candidats n'est publiée par le Conseil constitutionnel qu'après la collecte des 500 parrainages, vers la mi-mars 2027. D'ici là, ce tableau recense les candidatures déclarées, en primaire ou pressenties telles que rapportées publiquement. En savoir plus
